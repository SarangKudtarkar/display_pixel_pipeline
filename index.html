02VGA timing

A raster scan is just two counters. The horizontal counter sweeps through active pixels, front porch, sync, back porch; every time it wraps, the vertical counter steps. Watch the beam draw one frame.

h = 0v = 0 activehsyncvsync
blanking (porches) hsync vsync active video
Example timing: 640×480 @ 60 Hz → 800 × 525 total clocks per frame (H: 640+16+96+48, V: 480+10+2+33).

03Pixel FIFO

The pixel source and the display scan run at different effective rates, so a FIFO decouples them. Change the rates and see what happens when it fills or drains.

emptyfull level 0/8 overflow attempts: 0 underflow attempts: 0

Overflow (write while full) and underflow (read while empty) are exactly the kinds of conditions an SVA property or formal proof should rule out in the real design.

04Color conversion

The register file selects a pixel format. Pick a color and a format, then compare the bits going in with the bits coming out and the error introduced.

Grayscale uses Y = (77R + 150G + 29B) >> 8, an integer approximation of BT.601 luma. Narrow formats truncate low bits, then replicate high bits to expand back for display.

05APB register access

Software configures timing, pixel format and enable through APB. Every transfer is SETUP then ACCESS. Switch between write and read and replay.

06Verification flow

Simulation finds bugs with stimulus, assertions catch violations at the moment they happen, formal proves they cannot happen, and Python turns logs into a triage summary.
